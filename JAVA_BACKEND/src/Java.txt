[ 자바 실행순서 ]
    1. src 폴더 내  .java 확장자 핑ㄹ에서 java 코드 작성
    2. 빌드(build) : run java 실행. 
    3. [컴파일] bin 폴더 내 .class 확장자 파일 (자동) 생성

[주석]
    1. // 한줄주석
    2. /* */ 여러줄 주석

[용어]
    1. package : 해당 클래스가 위치한 폴더명
    2. class : 자바에서 컴파일 하는 최소의 단위 *클래스 {} 안에서 코드작성 *
    3. main함수 : 자바에서 코드를 읽어들이고 , 실행하는 흐름 = 스레드 제공
    4. ;세미콜론 : 코드의 한문장이 끝났다는 뜻. 해당 기준으로 컴파일한다.

[ 자료 ] : 데이터
    1. 리터럴 : 상수
    2. 자료타입 (형)
        1.  boolean     1byte      true/false
        2.  char           2byte     '' 감싼 문자1개저장
        3.  byte           1byte      -128 ~ + 127
        4. short           2byte     +-32000 정도  
        5. int               4byte     +-21억 정도              * (정수) 리터럴 타입 *
        6. long            4byte     +-21억 이상                끝에 L붙여야 함.
        7. float            4byte     소수점 8자리 표현      끝에 F붙여야 함.
        7. double        8byte     소수점 17자리 표현   * (실수) 리터럴 타입 *
        * String           N*2byte      ""감싼 문자 n개저장, 문자열객체(배열) 

[ 출력함수 ]
    1. Sysout.out.print( ) : 출력
    2. Sysout.out.println( ) : 출력+줄바꿈
    3. Sysout.out.printf( "형식문자" , 자료 ) : %s , %c, %d , %f 등
    * 이스케이프 / 제어문자 : \n , \t,       \'(<- ' 출력)  \" (<- " 출력)   \\ (<-\ 출력)

[ 입력함수 ] : 다양한 입력방식 제공.
    1. 입력객체 생성( 클래스 어디 1번씩 )
        Scanner scan = new Scanner(System.in);
    2. 입력객체 통한 입력함수( nextXXX() , 타입 주의 , 엔터기준으로 구분 )
        타입 변수명 = scan.nextXXX;
        * .nextLine() : 개행(/n) 사용하기 때문에 앞에 다른 .nextXXX() 존재 했을때 앞전 개행 포함
        예 .nextInt() ~ .nextline() : nextInt() 에서 3 입력 후 엔터(개행/n)  남는다. 
        해결방안 : .nextLine() 사이에 하나 추가한다. 
        .next() 문자열 [vs] .netxLine() 문자열 (띄워쓰기o)

[ ]
    * 다형성 : (하나의 자료/값) 다양한 형태(타입)
